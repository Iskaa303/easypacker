# easypacker

A simple TUI/CLI tool for creating Minecraft Modpacks.

## Acknowledgements

easypacker was inspired by [Pakku](https://github.com/juraj-hrivnak/Pakku), a multiplatform modpack manager
for Minecraft. Some code and design patterns have been adapted from that project.
